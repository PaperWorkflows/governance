## 1. 变更背景与动因
全库自查发现，各篇论文在面临字数带宽压制与防夸大贡献审查（PF-W3/PF-W10）时，产生了一系列防御性写作畸变：
1. 出现“不再重复”、“此处不赘述”、“同前所述”等公文甩锅式元话语；
2. 将内部审计/审查注记“（定位，非贡献）”、“未作扩大”、“协议要求声明”等生硬贴入大标题、表头与正文；
3. 密集出现缺乏因果解释的 API 说明书式电报跳转（如“具体字段参见5.4.3节”）；
4. 原单句 ≤40 字的机械朗读指标迫使 Agent 割裂完整复合从句。

同时，用户明确了目标刊官方过审样板《基于可信数据空间...-v4.5(1).pdf》的唯一合法定位：**仅作为物理版式的刚性契约，严禁吸收其正文措辞；学术正文写作修辞全面对标国际顶级学术长文**。
