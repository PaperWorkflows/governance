## 2. 刚性格式契约（必须 100% 遵守，一点不能擅改）
本文件是本项目各论文（P1–P10）物理版式与投稿外壳的**唯一实证真值源**。所有 Agent 在构建、排版与元数据生成时，必须严格执行以下规范：

1. **作者信息块排版**：
   - 正文上方作者栏格式严格遵循：`作者姓名（一级单位全称二级单位全称，所在市 邮政编码）`；
   - 通信作者姓名右上角标注星号 `*`；
   - 文末必须附完整作者简介块（包含出生年、性别、籍贯、学位职称、主要研究方向、电子邮箱、详细通信地址与邮编）。
2. **基金信息标注**：
   - 标注于文末或指定位置，排序严格为 `国家级 → 省部级 → 市级 → 校级`；
   - 格式严格为：`项目类型：项目全称（项目编号）`。
3. **参考文献著录与文内引用**：
   - 严格执行 **GB/T 7714 著者出版年制**；
   - 正文引用：单著者 `(Smith, 2020)` / `张三（2020）`；双著者 `(Smith & Chick, 2020)` / `张三和李四（2020）`；多著者 `(Smith et al., 2020)` / `张等（2020）`；
   - 文后著录：按著者汉语拼音字顺排列（中文在前，英文在后），专著 `[M]`、期刊 `[J]`、会议 `[C]`（必含会议地点）、预印本 `[EB/OL]`。
4. **摘要与关键词中英文排版**：
   - 中文摘要 300–400 字，必须使用第三人称，避免使用“本文/我们/作者”主语，禁止引文献、公式与特殊符号；
   - 英文标题、作者单位、摘要（Abstract）与关键词（Keywords）与中文完全镜像对应。
5. **分级序号与图表排版**：
   - 分级序号格式：`1`、`1.1`、`1.1.1`、`（1）`、`①`；
   - 图表遵循“先文字后图表”原则，必须具备完整图号/表号与中英文双语题注。
